## 1. 목적과 보관 원칙

이 폴더는 KREAM 검수 데이터 표준화 및 운영 개선 분석 **팀 프로젝트**의 발표 통계에 사용된 Pandas 집계 코드를 기록하기 위해 마련했습니다.

- 전달받은 **Python 파일 11개(통합본 1개, 개별 코드 10개)**를 `original/`에 보관합니다.
- 코드 본문의 계산식, 조건, 입력 경로, 주석을 **수정하지 않은 원본 자료**입니다.

- **원본 코드를 보관했다는 사실과, 이 코드로 최종 수치를 재현·검증했다는 주장은 다릅니다.** 최종 발표 지표의 검증 근거는 기존 프로젝트 검증 코드와 저장된 결과를 따릅니다.

## 3. 입력 데이터와 실행 전제

원본 Python 파일들은 다음과 같이 작성된 **Windows 상대경로**를 입력으로 사용합니다.

```python
df = pd.read_csv(
    r"data\Clean_(TO-BE)\clean_kream_inspection_joined.csv",
    low_memory=False
)
```

이 CSV는 현재 공개 GitHub 업로드 자료에 포함되지 않았습니다. 따라서 원본 스크립트를 다운로드하더라도 해당 파일이 준비되지 않으면 같은 경로에서 곧바로 실행할 수 없습니다. **이 보관본은 입력을 자동으로 내려받거나 그래프까지 생성하는 실행 패키지가 아닙니다.**

재현하려면 입력 CSV의 확보뿐 아니라 사용한 입력 버전과 분석 대상 조건의 확인이 필요합니다. 원본 코드의 입력 경로를 포함한 모든 내용은 기록 보존 목적으로 그대로 유지했습니다.

## 4. 원본 집계와 최종 검증 기준의 차이

원본 코드와 기존 프로젝트 검증 코드는 **분석 목적·대상 데이터·일부 필터에서 차이**가 있습니다. 아래 차이를 없앤 것처럼 설명하거나, 원본 코드 실행만으로 최종 발표 수치의 검증이 끝났다고 주장하지 않습니다.

| 대상 | 원본 Pandas 코드 | 프로젝트 최종 수치의 검증 기준 |
| --- | --- | --- |
| 재검수 집계(03번) | `REV_NO == 2`, 별도의 완료일 기간 조건 없음 | `REV_NO >= 2`와 검증 문서에 명시된 완료일 범위 적용 |
| 현재 상태·작업량(04번) | 결합 CSV에서 최신 상태와 전체 이력을 계산 | 최종 유효 상태와 유효 작업 이력을 **서로 다른 대상**으로 집계 |
| 직원 인원(07·08번) | 검수 결합 CSV에서 사번 중복 제거 | 정상 검수원 마스터를 기준으로 등록 인원 집계 |
| 상품 구성(05·06·09·10번) | 주로 상품명 `ITEM_NM` 사용 | 검증된 분석에서는 표준 상품 코드 기준 확인 |

원본 분석 조건을 바꾸지 않기로 했기 때문에, 위 차이는 **코드 수정이 아니라 문서로 공개**합니다. 원본의 특정 출력값이 최종 검증 결과와 완전히 일치하는지에 대해서는 이 폴더만으로 보장하지 않습니다.
